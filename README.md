# CoopKit (Fabric 1.20.1)

| Клавиша | Что делает |
|---|---|
| **K** | Меню читов: полёт, бессмертие, без урона от падения, ночное зрение, скорость, быстрое копание, без голода, дыхание под водой. |
| **B** | Поставить общую метку там, где стоишь. Видят все игроки. |
| **N** | Список меток: расстояние, кто поставил, удалить, ТП (если читы разрешены), вкл/выкл компаса. |

Нужен **Fabric API** и этот мод у всех игроков.
Настройки у хоста: `config/coopkit.properties`.
