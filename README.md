# CoopKit 1.4.1 (Fabric, Minecraft 1.20.1)

- **K** открывает меню читов. «Не тратить голод» поддерживает полную шкалу еды, пока чит включён. Хост может отдельно разрешать читы и телепортацию.
- **B** создаёт метку. Новая метка по умолчанию личная. Публичная видна всем, а старая общая метка остаётся публичной.
- **N** открывает список меток. «ТП себя» сразу отправляет к метке. «ТП игрока» показывает игроков, у которых есть доступ к ней.
- «Поделиться» позволяет автору дать доступ подключённому игроку, у которого ещё нет метки. Автор может удалить метку у всех. Остальные удаляют её только из своего списка.
- **Shift + ПКМ пустой основной рукой** превращает животное из списка доступных видов в съедобный предмет в руке. Удерживай **ПКМ**, чтобы его съесть. Предмет можно съесть при полной шкале голода. Подобранное животное исчезает из мира.

- Чтобы вернуть животное, возьми предмет в руку и нажми **Shift + ПКМ** по блоку, рядом с которым есть место. Восстанавливаются данные того же животного, включая имя, приручение, ошейник и окрас. Выпустить можно животных, подобранных начиная с 1.4.1.
- **H** переключает бхоп. Он доступен всем игрокам. Клавишу можно поменять в разделе CoopKit в настройках управления. Для разгона беги спринтом вперёд и прыгай подряд.

Установите Fabric API и одинаковую версию CoopKit у хоста и игроков. Настройки хоста лежат в `config/coopkit.properties`.

Для сборки на Windows с JDK 17 запустите `gradlew.bat build`. Файл мода появится в `build/libs`. В GitHub Actions готовый файл сохраняется в Artifacts у сборки Build CoopKit.

Доступно 18 видов. Когда игрок съедает приручённого питомца, в чат приходит одно из трёх сообщений с именем питомца и ником игрока.
